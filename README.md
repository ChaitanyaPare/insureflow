\# InsureFlow



A distributed insurance policy and claims management platform built for hands-on learning and interview preparation.



\## Technology Stack



\- Frontend: Angular, TypeScript

\- Backend: Java, Spring Boot

\- Microservices: Spring Cloud

\- Database: PostgreSQL

\- Caching and Rate Limiting: Redis

\- Messaging: Kafka

\- Security: Spring Security and JWT

\- Testing: JUnit, Mockito, Testcontainers

\- Deployment: Docker and Docker Compose

\- Monitoring: Spring Boot Actuator, Prometheus and Grafana



\## Planned Features



\- Customer authentication and role-based access

\- Insurance policy management

\- Premium payment simulation

\- Claims submission and approval

\- API Gateway and service discovery

\- Database transactions and distributed consistency

\- Rate limiting, caching and load balancing

\- Resilience, monitoring and automated testing



\## Learning Goals



Understand how distributed applications are designed, implemented, tested, secured, optimized and deployed.



\## Project Status



Initial setup and architecture planning.
